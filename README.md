# FutFin ⚽💰

Sistema de controle financeiro inspirado no futebol brasileiro.

## Funcionalidades

- Cadastro de receitas
- Cadastro de despesas
- Dashboard financeira
- Gráfico de movimentações
- Situação financeira dinâmica baseada no saldo

## Tecnologias

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## Como executar

```bash
pip install flask
py app.py
```

Acesse:

http://127.0.0.1:5000
